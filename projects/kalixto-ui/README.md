# kalixto-ui

Biblioteca Angular portátil de experiência web: tokens de design, sistema de motion
(reveal, stagger, text reveal, parallax, contador, progresso), header com dropdown e
menu mobile, footer, WhatsApp flutuante, i18n por URL, SEO/hreflang e componentes
(card, section header, acordeão, capítulo, sticky steps, section nav, CTA band).

Nada aqui é específico de um cliente, tudo entra por `provideKalixtoUi({ config, i18n, pages })`.

- Como usar em outro projeto: `../../docs/PORTABILITY.md`
- Catálogo e APIs: `../../docs/COMPONENTS.md`
- Efeitos e tempos: `../../docs/INTERACTIONS.md`

Build: `npx ng build kalixto-ui` → `dist/kalixto-ui` (inclui `styles/`).
